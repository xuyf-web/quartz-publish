# 引言

最近一段时间，人工智能领域掀起了大模型应用的爆发浪潮。从通用型语言模型到专业领域工具平台，各类智能产品以远超（我的）预期的速度密集迭代。这种百花齐放式的技术井喷固然令人欣喜，但作为使用者更需思考：如何在 AI 浪潮中获取自己真正需要的那一个解决方案？我认为关键在于将工具落地到应用场景中，只有实际用到，才能搭建出融合 AI 技术的生产力系统，实现科研效率与生活质量的全面提升。

本文基于对全球多款主流 AI 模型与工具的试用评测，从一个博士生的视角出发，梳理当前阶段兼具实用价值与创新突破的解决方案。

# AI 大模型

![[AImodels.png]]

首先简单列一下我了解的大模型

* **ChatGPT**（OpenAI）
	* 好用，能力强
	* 贵，网络条件限制
	* T0 水平，即将发布的 GPT5 将免费开放；经费充足可冲 PLUS
* **Claude**（Anthropic）
	* 代码功能比较强
	* 网络条件限制
	* 我用得很少
* **通义千问**（阿里）
	* 服务稳定，功能全面
	* 代码能力差一点
	* 是我理想中 AI 的样子，国行设备的 Apple AI 是与通义合作让我很安心
	* 过年期间推出了 Qwen-Max 能力更强了
* **豆包**（字节跳动）
	* 语音最好听的大模型，我用来日常对话聊天
	* 豆包有浏览器插件，总结网页内容很方便
	* 还有专门的豆包浏览器，功能很丰富，但我有时觉得它做了太多（怎么哪都有它），会有点烦
* **DeepSeek**（幻方量化）
	* 年前爆火到现在的“争气”国产大模型
	* V3 的 API 服务价格非常便宜
	* R1 的思索过程很牛，我认为目前对中文的支持独一档
* **Kimi**（月之暗面）
	* 以超长上下文出名，可阅读大量文本、PDF 等
* **混元大模型**（腾讯）
	* 功能比较一般，但服务稳定
* **Gemini**（Google）、**智谱清言**（清华）、**星火**（讯飞）、**文心一言**（百度）
	* 用得少，略过
* **Ollama**
	* 在本地部署大模型，可以避免上传敏感文件，私密性好
	* 受到本地算力限制，基本只能安装蒸馏过的大模型，能力比完整版弱很多
	* 没有特殊需求没必要折腾
* 最近更新
	* **Gemini** 发布 2.0，**Grok** 发布 3.0

# AI 工具

以下是我了解到一些能利用 AI 的软件或平台

**辅助代码编辑**：Copilot，通义灵码，Codeium，CodeGeex，Tabnine，MarsCode 等。我目前用的是 Copilot，申请过 Github 学生开放包即可免费用

![[Pasted image 20250219212355.png]]

**深度搜索**：ChatGPT，Perplexity，秘塔搜索。国外的两家都要钱，秘塔免费可用，可以让它简单地输出一篇综述试试，用过后记得回来点赞。

![[Pasted image 20250219212754.png]]

**节点交互式 AI 工具**：Flowith，非常新颖的问答方式，可以在对话过程中的任意节点展开新的问答

![[Pasted image 20250219213006.png]]

**追踪关注的领域和话题**：Syft。如果你知道 RSS，这就是一个 AI 加持下的 RSS 订阅平台，不需要你自己去找订阅源，Syft 会帮你搞定，但这也可能意味着其喂给你的内容良莠不齐。

![[Pasted image 20250219213020.png]]

**处理文档**：Doc2X，ChatDOC

![[Pasted image 20250219213246.png]]

**处理数据图表**：ChartCube，需要上传数据，所以我基本用不到。

**绘图**： DALL-E，Recraft，海螺，即梦，可灵。用来做个概念图还是可以的。

![[Pasted image 20250219213305.png]]

**智能体**：百宝箱（支付宝），Dify。这个好像是最新的一类 AI 工具，可以自己设定工作流，能处理更复杂、专业度更高的任务，我还没有上手，等待后续研究。

![[Pasted image 20250219213637.png]]

**知识库**：ima（腾讯）- 能接入微信公众号的内网生态是它唯一的优势，但这个优势太大了；AnythingLLM 或 LM Studio 配合 Ollama 本地大模型构造知识库

# 本地软件接入 API

官方大模型均提供付费 API （Application Programming Interface）服务，使得在本地软件中可以方便地利用 AI 能力。一般使用的是 ChatGPT、通义千问、DeepSeek 的 API，也有硅基流动（SiliconFlow） 这样的平台综合提供各个模型的 API。

下面是我常用到 API 的地方，做简单的分享。

* **VS Code 插件**：Cline 或 Roo Code 等
	* 给予权限后可以阅读、创建、修改本地文档并执行命令，可以做多轮的自我对话，出现问题能能够做到自我纠错。真正解放基础的代码工作
* **Obsidian 插件**：Copilot in Obsidian 或 Smart Composer 等
	* 根据笔记内容和 AI 做对话，对笔记内容做补全
* **Zotero 插件**：Awesome GPT 或 PapersGPT 等
	* AI 辅助阅读文献，帮助总结文献内容。
* **本地翻译服务**：STranslate（Windows）、Pot（macOS）等
