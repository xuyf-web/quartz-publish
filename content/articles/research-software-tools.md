# 前言

作者目前正在读研，专业方向是大气科学。

本系列分享几个本人常用的软件和工具，主要是对科研有帮助的软件。

我目前使用的设备是 ① Windows10 22H2 ② IOS 17.4.1，软件适配情况仅供参考。

---

# 截图软件

【Snipaste】是非常好用的一个截图、贴图软件，可以将选中的区域以贴图的形式固定在屏幕顶层，方便我们查看不同页面上的内容，尤其在看文献时就非常有用了。

一般的功能都有，比如正常截图保存、截图添加注释。还有一些附加功能，比如取色器，选取屏幕上点的色值。

除了 Snipaste 外，近期有一个新的软件【Pixpin】可供选择。Pixpin 除了 Snipaste 里上述功能外，还可以实现 OCR 文本识别、长截图、截动图等功能，功能更丰富，大家可以尝试。

不过作者试用后觉得流畅度方面尚不如 Snipaste，因此没有换用。Snipaste 免费版够用，强烈推荐。

# 文件管理

作者长期使用 Windows 资源管理器管理文件，但在窗口管理上略有不便，当查看文件时往往需要在多个上下级路径间来回切换，常常需要同时打开多个资源管理器界面操作，非常混乱，看着不爽。

个人认为最好可以实现像浏览器一样管理窗口，现在有许多软件可以帮助解决这一问题。

如果你习惯了默认的资源管理器，【QTTabBar】是最好的选择。它是安装在资源管理器基础上的插件，提供了多窗口管理、书签管理等功能，还可以实现双击空白处返回上一级、按住 CTRL 键双击文件夹在新窗口中打开等快捷功能（大量快捷键支持自定义）。

如果你希望尝试不一样的文件管理界面，可以试试【OneCommander 3】，整体界面美观，可水平或垂直切分窗口，甚至可以创建多个工作区，在不同工作区打开不同的路径。此外，该软件也集成了双击空白处返回上一级、选中文件后空格键预览内容（类似 QuickLook）等功能，极大提高了我的使用效率。目前免费版够用，强烈推荐。

除此以外，还有许多软件可供尝试，如 Clover、XYexplorer 等。

# 剪贴板记录

我们在电脑上都会复制诸多内容，有时想找到复制或剪贴的历史，但默认情况下会被新的内容覆盖掉，怎么办？

这里推荐一个老牌、免费的剪贴板记录工具【Ditto】，它可以记录数百条复制的历史记录，可通过快捷键随时调出。在不用它的时候，它就静静留在工具栏，不会打扰我们。

也许你知道 Windows 系统较新的版本默认支持记录剪贴板历史了，但它不像 Ditto 一样支持在历史中搜索的功能，时至今日仍然不好用。因此我仍然会推荐使用 Ditto。

# 查找文件工具

在 Windows 资源管理器中搜索文件曾经让我很苦恼，速度极慢，而且最后很可能搜索不到结果。

推荐使用【Everything】工具，可以实现快速搜索文件功能，并且支持正则表达式，方便了很多。但是使用 Everything 也需要注意空间占用问题，它会把文件重建索引，使用时间久了可能占用一定量的磁盘空间。

Everything 也不能完美满足我的需求，因为它只能搜索文件名称，但有时我想搜索的是文件内容。这里推荐大家使用【AnyTXT Searcher】，可以搜索到文件内部的字符。

# 综合工具

除了上述软件外，我们有时还会遇到一些小问题，比如批量重命名文件、OCR 获取文本等，实际上也都有相应的软件专门解决这些问题。

我这里推荐一个软件平台【UTools】，里面丰富的插件可以方便地实现这些小功能，甚至也包括上述提到的“剪贴板历史”、“文件搜索”等功能。

# 总结

本文分享了几个我个人长期使用的效率软件，不含任何广告，纯粹是软件用得好，希望能帮到读者。
