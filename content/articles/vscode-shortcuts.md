VS Code 自带了非常丰富的快捷键，你都知道吗？用好了能够极大提高工作效率！

# 1. 多选光标

选中某段代码，按下【CTRL+D】可以同步选中文本里内容相同的代码部分，之后可以在多个光标下同步修改。

![[vscode快捷键1.gif]]

如果你只是想在某些特定位置添加光标同步修改，可以按住【Alt】键在任意地方单击，即可出现多个光标。

![[vscode快捷键2.gif]]

# 2. 添加注释

光标放在选中代码行任意位置，按下【CTRL+/】，可以便捷注释

![[vscode快捷键3.gif]]

# 3. 移动代码行

光标放在选中代码行任意位置，按下【ALT+↑/↓】，可以移动整行代码位置

![[vscode快捷键4.gif]]

# 4. 全文替换

按下【CTRL+H】，可以对全文指定代码内容做替换，该操作对 Jupyter Notebook 同样适用

![[vscode快捷键5.gif]]
